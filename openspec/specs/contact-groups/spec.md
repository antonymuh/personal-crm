# contact-groups Specification

## Purpose

Помогает раскладывать контакты по своим группам (семья, друзья, теннис и т.п.) и быстро смотреть только нужную группу.

## Requirements

### Requirement: Название группы
Группу SHALL создавать пользователь сам, с любым непустым названием. Пробелы по краям названия отбрасываются. Названия групп SHALL быть уникальными без учёта регистра: «Теннис» и «теннис» — одна и та же группа. Изначально групп нет.

#### Scenario: Пустое название
- **WHEN** пользователь пытается создать или переименовать группу с названием из одних пробелов
- **THEN** группа не создаётся и не меняется, видна ошибка «Укажите название группы»

#### Scenario: Пробелы по краям
- **WHEN** пользователь создаёт группу с названием «  Теннис  »
- **THEN** группа называется «Теннис»

#### Scenario: Групп нет изначально
- **WHEN** фича выкачена на базу с уже существующими контактами
- **THEN** групп нет, ни один контакт не входит в группу, и список выглядит как раньше, только с фильтром «Все»

### Requirement: Группы в форме контакта
Формы «Добавить контакт» и «Изменить контакт» SHALL показывать все группы по алфавиту с галочками и поле «Новая группа». Отмеченные группы сохраняются у контакта, снятые галочки убирают контакт из группы. Контакт может входить в несколько групп или ни в одну.

#### Scenario: Контакт в нескольких группах
- **WHEN** пользователь добавляет контакт и отмечает группы «Друзья» и «Теннис»
- **THEN** контакт состоит в обеих группах

#### Scenario: Без групп
- **WHEN** пользователь добавляет контакт, не отмечая ни одной группы
- **THEN** контакт не входит ни в одну группу

#### Scenario: Убрать из группы
- **WHEN** пользователь открывает «Изменить» у контакта из групп «Друзья» и «Теннис», снимает галочку «Теннис» и сохраняет
- **THEN** контакт состоит только в группе «Друзья», а группа «Теннис» остаётся

#### Scenario: Галочки отражают текущие группы
- **WHEN** пользователь открывает «Изменить» у контакта из группы «Семья»
- **THEN** галочка «Семья» уже отмечена, остальные — нет

### Requirement: Новая группа из формы контакта
Если в поле «Новая группа» введено название, при сохранении контакта SHALL создаваться группа с этим названием, и контакт сразу в неё попадает. Если группа с таким названием (без учёта регистра) уже есть, новая не создаётся: контакт попадает в существующую. За одно сохранение создаётся не больше одной новой группы.

#### Scenario: Создать группу при добавлении контакта
- **WHEN** групп нет, пользователь добавляет контакт и вводит в «Новая группа» название «Семья»
- **THEN** появляется группа «Семья», контакт в ней состоит

#### Scenario: Название уже есть
- **WHEN** группа «Теннис» существует, а пользователь при изменении контакта вводит в «Новая группа» «теннис»
- **THEN** вторая группа не появляется, контакт попадает в «Теннис»

#### Scenario: Новая группа вместе с галочками
- **WHEN** пользователь отмечает группу «Друзья» и вводит в «Новая группа» «Аналитики»
- **THEN** контакт состоит в группах «Друзья» и «Аналитики»

#### Scenario: Ошибка в форме не теряет группу
- **WHEN** пользователь вводит «Новая группа» «Аналитики», но оставляет имя контакта пустым и сохраняет
- **THEN** видна ошибка «Укажите имя контакта», ни контакт, ни группа не создаются

### Requirement: Метки групп у контакта
У контакта SHALL быть видны метки всех его групп по алфавиту — в карточке контакта и в списке контактов. У контакта без групп меток групп нет.

#### Scenario: Метки в карточке
- **WHEN** пользователь открывает карточку контакта из групп «Теннис» и «Друзья»
- **THEN** видны метки «Друзья» и «Теннис»

#### Scenario: Метки в списке
- **WHEN** в списке есть контакт из группы «Семья»
- **THEN** у него в списке видна метка «Семья»

#### Scenario: Без групп - без меток
- **WHEN** контакт не входит ни в одну группу
- **THEN** ни в списке, ни в карточке меток групп у него нет

### Requirement: Фильтр списка по группе
Над списком контактов SHALL быть фильтр: «Все» и все группы по алфавиту. По умолчанию выбрано «Все». При выборе группы в списке остаются только её контакты; счётчик показывает их число. Одновременно выбирается одна группа. Фильтр работает вместе с поиском по имени, порядок и метка «Пора связаться» — те же, что без фильтра. Выбранная группа видна в адресе страницы.

#### Scenario: Выбрать группу
- **WHEN** в базе «Анна» (Семья), «Борис» (Теннис) и «Вера» (Семья, Теннис), пользователь выбирает фильтр «Теннис»
- **THEN** в списке только «Борис» и «Вера»

#### Scenario: Вернуться ко всем
- **WHEN** выбран фильтр «Теннис» и пользователь выбирает «Все»
- **THEN** в списке снова все контакты

#### Scenario: Фильтр и поиск вместе
- **WHEN** выбран фильтр «Семья» и пользователь ищет «Ве»
- **THEN** в списке только «Вера»

#### Scenario: Порядок «пора связаться» внутри группы
- **WHEN** выбран фильтр группы, и среди её контактов есть «пора связаться»
- **THEN** такие контакты идут первыми с меткой «Пора связаться», как и во всём списке

#### Scenario: Пустая группа
- **WHEN** пользователь выбирает группу, в которой нет контактов
- **THEN** видно сообщение, что в этой группе пока никого нет

#### Scenario: Ссылка на группу
- **WHEN** пользователь выбрал фильтр «Теннис» и открыл тот же адрес в другом браузере
- **THEN** там тоже выбран фильтр «Теннис» и видны те же контакты

#### Scenario: Группы больше нет
- **WHEN** пользователь открывает адрес с фильтром по группе, которой уже нет
- **THEN** показывается весь список с выбранным «Все»

#### Scenario: Групп ещё нет
- **WHEN** ни одной группы ещё не создано
- **THEN** фильтр не показывается, список выглядит как раньше

### Requirement: Переименование группы
Когда в фильтре выбрана группа, рядом SHALL быть кнопка «Переименовать». Новое название подчиняется тем же правилам, что и при создании. Контакты группы при переименовании не меняются.

#### Scenario: Переименовать
- **WHEN** выбрана группа «Тенис» с двумя контактами, пользователь переименовывает её в «Теннис»
- **THEN** группа называется «Теннис» в фильтре, в формах и в метках, в ней те же два контакта

#### Scenario: Название занято
- **WHEN** есть группы «Друзья» и «Семья», пользователь переименовывает «Семья» в «друзья»
- **THEN** переименование не происходит, видна ошибка «Группа с таким названием уже есть»

#### Scenario: Смена только регистра
- **WHEN** пользователь переименовывает группу «теннис» в «Теннис»
- **THEN** группа называется «Теннис»

### Requirement: Удаление группы
Когда в фильтре выбрана группа, рядом SHALL быть кнопка «Удалить». Перед удалением пользователь подтверждает действие. Удаляется только группа: её контакты остаются и просто перестают в ней состоять. После удаления выбран фильтр «Все».

#### Scenario: Удалить группу
- **WHEN** пользователь удаляет группу «Теннис», в которой «Борис» и «Вера», и подтверждает удаление
- **THEN** группы «Теннис» нет в фильтре, в формах и в метках, «Борис» и «Вера» остались в списке, у «Веры» сохранилась группа «Семья», показан весь список

#### Scenario: Передумал
- **WHEN** пользователь нажимает «Удалить» у группы и отменяет подтверждение
- **THEN** группа и её контакты не меняются

### Requirement: Удаление контакта и группы
При удалении контакта SHALL удаляться только его членство в группах; сами группы остаются, даже если опустели.

#### Scenario: Удалили единственный контакт группы
- **WHEN** в группе «Аналитики» один контакт, и пользователь удаляет этот контакт
- **THEN** группа «Аналитики» остаётся в фильтре, в ней никого нет

### Requirement: Группы хранятся на сервере
Группы и членство в них SHALL храниться на сервере: в любом браузере видны одни и те же группы.

#### Scenario: Другой браузер
- **WHEN** пользователь создал группу «Теннис», добавил в неё контакт и открыл приложение в другом браузере
- **THEN** там есть группа «Теннис» с этим контактом
